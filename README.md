# CMS-Dashboard UI

A clean and modern Admin Dashboard Table UI built using HTML, CSS, and JavaScript, designed pixel-perfect according to a Figma design.
link : https://nimrazulfiqar-002.github.io/CMS-Dashboard/

📌 Project Overview

This project is a admin dashboard  interface that includes:

sidebar for dashboard
data Table 
Edit/Delete Actions
Pagination
Items Per Page Dropdown
Clean UI based on Figma design (Pixel Perfect)

The goal of this project was to practice real-world frontend development and converting Figma design into code.

🎨 Design

I designed and developed this UI pixel-perfect from a Figma design.

The Figma design link here.
